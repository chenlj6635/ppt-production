# PPT 制作与验收

用于 PPTX 制作及排版修改。保留用户指定的交付格式、模板和修改范围；本技能提供可按项目覆盖的默认偏好，用户当次明确要求优先。具体模板、配色和本机路径以项目 AGENTS.md 为准。可与宿主的演示文稿工具配合使用。

## 工作顺序

1. 有参考模板时先测量画布、标题/正文字号、页眉/页脚边界，再排版；见 `references/measure-template.md`。分别报告直接测量、继承属性和未核实项。
2. 先辨明参考文件用途：用户指定为整套模板时，从副本保留母版/主题；若为优秀 PPT 素材合集，按语义选用局部结构，统一到目标稿样式，不默认继承整库主题或清空素材源。修订现有稿沿用已确认样式，仅改指定范围。
3. 完成后导出 PDF 并逐页转图，打开每一页检查；清单见 `references/layout-checklist.md`。发现问题后修改、重新渲染受影响页。
4. 运行 `python <skill_dir>/scripts/pptx_audit.py <deck.pptx> --min-pt 20` 辅助检查。最终交付须说明渲染和检查是否完成；渲染受阻只能称为未验收草稿。

## 区域结构化与素材取用

采用用户的区域结构化偏好：文字、图片、表格先按共同含义组成有职责的结构单元，再通过对比、因果、流程、总分或证据汇聚组织整页逻辑，最后统一对齐、间距、颜色与视觉主次。优先选用素材库中的“标题—框—内容”结构，避免游离小文本；原生透明文本框可作为区域内部元素和图像标注。结构应服务内容，不固定区域数量或把每页套成同样的卡片网格。

制作或改版时读取 `references/regional-structure.md`，其中包含取用流程、验收问题及随附素材库入口。先读 `assets/library/index.md` 筛选候选，再查看对应预览和原生源文件；新增或刷新素材时读取 `references/library-workflow.md`。用户当次指定的设计优先；本机素材库不可访问时说明限制。素材库提供局部结构和逻辑范例，不自动规定所有项目的主题、颜色或科学结论。

## 内容与排版偏好

- 正文、表格、图注默认至少 20 pt；页码保留模板大小。放不下先精简或拆页，具体场景的例外由用户指定。引用图片中的文字另行读图检查，脚本不做 OCR。
- 独立内容区域不得互相遮挡、越界或压住页眉线。背景、图片标注和组合内部的有意叠放允许存在，以渲染结果是否清晰为准。
- 框高贴合内容，保持稳定内边距；避免一行文字占三行高度和大量无目的留白。
- 避免装饰性的“三点式并列小字”；用完整句或分行短句。讲稿、时间分配、强调提示留在备注，不写进正文。
- 内部汇报封面通常只留标题、报告人、时间；正式答辩遵循指定模板的导师、单位等字段。
- 金额和数量与正文同档字号，不为强调而额外放大。

## 渲染前的易错项

- 状态用“首选/已排除/谨慎”等文字表达，避免勾叉、警告、星号等容易缺字的图形字符。数学符号、希腊字母正常保留，读图确认字形。
- 同时设置拉丁字体和东亚字体。编辑 XML 时使用完整命名空间；判断元素是否存在用 `is None`，不要用空 XML 元素的真假值。
- 标题标签放在合适的绘制层，避免后添加的图片遮字；不为了图层顺序让标签压住页眉线。
- 表格按实际渲染高度留空间。20 pt 行高约 0.44–0.55 in 只能作起点，字体、换行、内边距都会改变它。
- 检查复制版式后页码是否存在、位置是否可见；空标题占位符可合法保留。清除肉眼可见的示例文字和未完成标记。

## 导出与审计的边界

PPTX 使用可用的 PowerPoint 或 WPS 演示导出 PDF，再用 Poppler 栅格化。Windows 的 COM ProgID 为 `PowerPoint.Application` 和 `Kwpp.Application`；注册存在只代表可以尝试，不等于本次导出成功。Word COM 不承担 PPTX 导出。导出时保留当前正在编辑的文稿，不关闭他人的窗口。

审计支持 `--json` 和 `--overlap-threshold 0.30`：

- `font-below-floor` 为明确字号违规；纯数字也属于正文，只有真正的页码占位符/字段豁免。
- `font-inherited-review` 表示未解析到显式/段落字号，需要检查母版或渲染结果，不能当作通过。
- `symbol-glyph-review`、`overlap-review` 仅提示检查，不证明缺字或真实遮挡。重叠只比较顶层有效内容区域，忽略空占位符、纯装饰和整页底图；组内文字仍检查字号。
- 退出码 0 表示未发现明确字号违规，1 表示有违规，2 表示无法检查；**0 不等于视觉验收通过**。包围框检查不替代溢出、压线、组内布局和逐页读图。

覆盖已有交付文件前保留备份；布局修订默认保留原文，涉及内容变化时以用户指定范围为准。
